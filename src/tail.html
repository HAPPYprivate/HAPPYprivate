FAQ

Is HAPPY Script free?

Yes. HAPPY Script is free. Use Copy Script to get the loader.

Which HAPPY Midi tools are free?

Generate is free. Sheet Studio and Check Display for MIDI are paid software.

What is a .happy file?

A format built for Happy Macro. Sheet Studio is the official tool for exporting complete .happy files, so a plain MIDI file will not use all of Happy Macro.

Is Generate or Check Display 100% accurate?

No. Both depend on source quality and settings. Expect to review and edit results, ideally in Sheet Studio.

Is Macro Gamer part of HAPPY Midi?

No. Macro Gamer is an independent program by another developer. Generate can export .mgp files for it, with no official partnership.

How do I buy software?

Purchase buttons open an external page. Buttons without a link are marked Coming soon.
